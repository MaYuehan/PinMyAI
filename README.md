# 📌 PinMyAI

**PinMyAI** 是一个浏览器扩展，让你可以在 ChatGPT 对话中标记重要的回复片段，随时一键跳回 —— 再也不用在长对话里疯狂滚动了。

![Chrome Extension](https://img.shields.io/badge/platform-Chrome-blue) ![Version](https://img.shields.io/badge/version-1.0.0-green) ![Status](https://img.shields.io/badge/status-active-brightgreen)

---

## 🎯 解决什么问题？

在和 AI 的深度对话中，你经常遇到这样的情况：

1. AI 回复了一个你不懂的术语
2. 你追问「什么是 XXX？」
3. AI 给出详细解释
4. 你想回到原来的位置继续看 -- 但对话已经滚了十几屏 😫

**PinMyAI 就是你的「对话书签」**：选中 → 标记 → 随时跳回。

---

## ✨ 核心功能

### 📌 添加 Pin
- 选中 AI 回复中的任何文字
- 点击弹出的 📌 按钮
- 输入名称（自动取文字前 20 字）

### 📂 管理面板
- 右上角 📌 图标打开面板
- 查看当前对话的所有 Pin
- 支持重命名、删除
- 支持三种排序：按时间（最新/最旧）/ 按对话顺序

### 🌐 跨对话跳转
- 全局视图：查看所有对话的 Pin
- 点击其他对话的 Pin → 弹窗选择：新标签页 / 当前窗口 / 取消

### 🎯 精确跳转
- 跳转到**精确的文字位置**（不是整条消息）
- 柔和的高亮动画（浅蓝色，5 秒）

## 🚀 安装方法

### 开发模式安装

1. 下载或克隆本项目
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角 **「开发者模式」**
4. 点击 **「加载已解压的扩展程序」**
5. 选择项目文件夹

## 🎮 使用指南

### 添加 Pin

1. 在 AI 回复中选中你想标记的文字
2. 点击弹出的 📌 按钮
3. 输入 Pin 的名称（或直接保存）
4. 右上角面板会实时更新

### 跳转到 Pin

- **当前对话的 Pin**：直接点击，立即跳转 + 高亮
- **其他对话的 Pin**：点击后选择打开方式

### 管理 Pin

- 点击右上角 📌 打开面板
- 点击 ✏️ 重命名
- 点击 🗑️ 删除（有确认弹窗）
- 切换排序方式：按时间 / 按对话顺序
